同步辐射光纤束路重接 · 辫群等价复核

以辫群 Bn 的 Garside 左贪婪规范形精确判定两条重接记录是否等价；计算在浏览器 Worker 中执行。

语法：发生器 σ1…σ(n-1)（亦接受 s1 或裸数字）；逆元写作 σ1^-1、σ1^{-1}、σ1' 或 σ1⁻¹； 符号以空白分隔；空记录 = 单位元；每条记录 ≤ 80 个符号。

方法说明

每条记录被归约为唯一的 Garside 左贪婪规范形 Δ^k · A₁ A₂ … A_m（Aᵢ 为真简单元，相邻对左权重）。 两条记录等价，当且仅当两侧规范因子链逐项相同；不等价时给出首个分歧因子。

逆元按 σᵢ⁻¹ = ∂σᵢ·Δ⁻¹ = Δ⁻¹·τ(∂σᵢ) 精确改写（Δ 移动时对途经因子施加翻转自同构 τ）， 远交换（|i−j|≥2）与三项编织关系（σᵢσᵢ₊₁σᵢ = σᵢ₊₁σᵢσᵢ₊₁）均由规范形的唯一性覆盖。 判定不依赖有限次试变换、随机改写，也不仅凭诱导置换：即使两侧诱导置换同为恒等，只要规范链不同即判不等价。
